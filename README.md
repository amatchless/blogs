# Amatchless blog

Source for the weekly SEO blog on https://amatchless.com: content calendars, posts, graphics and the tools that build them.

- `blog/blog-style-guide.md` — standing rules for every post and the publishing process
- `blog/calendars/` — monthly content calendars (one post per Friday)
- `blog/topic-backlog.md` — scheduled and unscheduled topics
- `blog/week-NN-<slug>/` — one folder per post: research, `post.md`, built HTML, `images/`
- `blog/templates/graphics/` — the brand graphics kit (covers and in-post graphics)
- `research/`, `brief/` — competitor research and the brand/services brief

Schedule (IST): calendar for next month on the last day of each month; post written and drafted Thursday; published Friday.
